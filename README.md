# Изучаем Git

Это учебный проект для знакомства с коммитами и командами Git. Страница находится в `index.html`.

## Алиасы

Файл `git-aliases.config` содержит сокращения команд. Он подключён к настройкам этого репозитория через скрытый файл `.git/config`, поэтому алиасы действуют здесь автоматически.

| Команда | Что показывает или делает |
| --- | --- |
| `git s` | Краткое состояние файлов |
| `git l` | История коммитов в виде графа |
| `git g` | Подробная цветная история |
| `git br` | Список веток |
| `git co имя-ветки` | Переключение на ветку |

Чтобы посмотреть историю, введи `git l` в терминале VS Code. Коммит — это сохранённый снимок изменений проекта. После изменения файла можно создать новый коммит командами `git add index.html` и `git commit -m "Описание изменения"`.

Настройки из `git-aliases.config` подключены только на этом компьютере для этого репозитория. После нового клонирования можно подключить их командой `git config --local include.path ../git-aliases.config`.
