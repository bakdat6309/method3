# Изучаем Git

Учебный проект `git-ui` для практики с коммитами, ветками и слиянием. На странице [index.html](index.html) собраны базовые команды Git и краткие пояснения к ним.

## Запуск

1. Открой папку проекта в VS Code.
2. Открой `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Практика с ветками

### Посмотреть историю

```bash
git status --short
git log --oneline --graph --decorate --all
```

На GitHub можно открыть историю ветки и нажать на хеш коммита, чтобы увидеть его изменения. Для сравнения целиком открой [разницу между `git-ui-main` и `git-ui-develop`](https://github.com/bakdat6309/method3/compare/git-ui-main...git-ui-develop).

### Слить `develop` в `main`

Сначала сохрани незакоммиченные правки. Перейди в `main` и выполни слияние:

```bash
git switch main
git merge develop
```

Если `main` не получила новых коммитов после ответвления, Git выполнит **fast-forward**: передвинет `main` на последний коммит `develop`. Если Git сообщит о конфликте, открой отмеченные файлы, оставь нужный код, добавь их через `git add` и выполни `git merge --continue`.

## Алиасы Git

В [git-aliases.gitconfig](git-aliases.gitconfig) лежат сокращения для терминала. После клонирования обычные команды Git работают сразу. Алиасы доступны, когда файл подключён в настройках репозитория.

| Алиас | Действие |
| --- | --- |
| `git s` | Показать состояние файлов |
| `git l` | Показать краткий граф коммитов |
| `git g` | Показать подробный цветной граф |
| `git br` | Показать список локальных веток |
| `git co develop` | Переключиться на ветку `develop` |
